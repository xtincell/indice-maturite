# Indice de maturité créative ADVE

**Le diagnostic d'entrée.** Seize questions, quatre axes, un niveau de 0 à 5 — et une
prescription : ce que la marque doit acheter ensuite, et pourquoi.

C'est ce mécanisme qui rend la vente **rationnelle plutôt que persuasive** : le produit
payant devient l'ordonnance du diagnostic gratuit.

## Position au portefeuille

Produit **00 · Acquisition** de [Creative Next](https://github.com/xtincell/shinkiro/blob/main/docs/PORTFOLIO.md).
Gratuit, 20 minutes, qualification.

C'est le seul produit du catalogue où **l'outil *est* l'offre**. Partout ailleurs, la
technologie reste derrière le rideau ; ici, elle est le livrable.

| | |
|---|---|
| Ce que le prospect obtient | 3 opportunités concrètes · 1 recommandation prioritaire · un aperçu du potentiel de gain |
| Ce qu'il ne faut pas lui donner | Assez de valeur pour créer l'envie, jamais assez pour remplacer l'audit payant |
| Ce qu'il achète ensuite | **Creative Operations Audit** — 450 K FCFA, 7-10 jours |

## Lancer

Ouvrir `index.html`. Aucun serveur, aucune installation, aucune dépendance.

## Les quatre axes

Le diagnostic porte sur les quatre piliers ADVE — **A**uthenticité, **D**istinction,
**V**aleur, **E**ngagement. Quatre questions par axe, seize au total. Le score composite
situe la marque sur une échelle de 0 à 5, et la prescription en découle.

## Rôle dans Shinkiro

Couche 01 · méthode. Voir [`shinkiro`](https://github.com/xtincell/shinkiro) pour
l'architecture du programme.
